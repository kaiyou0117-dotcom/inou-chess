# 異能チェス

「ここだけ異能のある世界」の設定を元にした、HP/ATK制の特殊駒チェス。GitHub Pages でそのまま公開できる構成。

## 構成
```
index.html          トップ・メニューページ(モード選択)
formation.html       編成モード(現状は初期配置固定の盤面ゲーム)
roguelike.html        ローグライクモード(準備中プレースホルダー)
common.css            全ページ共通(デザイントークン・ヘッダー・ボタン等)
board.css              盤面ゲーム画面専用(編成モード等で使用)
menu.css               トップページ・準備中ページのカードUI
engine.js              盤面ロジック・駒データ(編成モードが読み込む)
```
全ファイルをリポジトリ直下にフラットに配置する構成。各HTMLは`common.css`を土台に、
そのページ専用のCSS(`board.css`または`menu.css`)を重ねて読み込む。
新しいモードを追加する際は直下に新しいHTMLを置き、`common.css`を読み込んだ上で
必要なCSS/JSを足していく想定。

## 公開方法
1. このフォルダの中身をリポジトリ直下(または `docs/` フォルダ)に配置
2. リポジトリの Settings → Pages で公開元ブランチ/フォルダを指定
3. トップページ(`index.html`)からモードを選ぶと `formation.html` / `roguelike.html` に遷移

## データ構造
`engine.js` の `PIECE_TYPES` は役割ごとに `variants.special` / `variants.normal` の
2バリエーションを持つ構造。駒生成時に `makePiece(type, color, variant)` の第3引数で
どちらを使うか選べる(省略時は `"special"`)。編成モード実装時はこの仕組みをそのまま使い、
盤面初期化時にスロットごとにvariantを選択する想定。

## 現状の実装範囲
- 8x8盤面の表示、初期配置、駒のクリック選択、合法手ハイライト
- 標準的なチェスの動き(ポーン/ナイト/ビショップ/ルーク/クイーン/キング)による移動
- **HPダメージ制の戦闘解決**：敵駒への攻撃はATK分だけ相手のHPを削り、0以下で撃破(攻撃側がマスへ進出)。耐えた場合は双方その場に留まり、次ターンへ
- **特殊能力4種**
  - 海洋恐怖症(ビショップ)：移動成立時、前後左右いずれかの空きマスに式神(ポーン)を召喚
  - 情報の悪魔(ナイト)：移動成立時、縦横1マスの全ての駒(敵味方問わず)を破壊。「レンレン」がいれば無効化(レンレン駒は未実装のため現状は常に発動)
  - 鉄拳の悪魔(ルーク)：直線移動で最初にぶつかった駒を1体だけ(敵味方問わず)飛び越えられる
  - 社畜魔導士(ポーン)：最奥列到達で「コードネームAMBER」に変身。動き(クイーン/ルーク/ビショップ/ナイト型)をモーダルで選択。変身後は1ターンに2回まで行動可能(捕獲は1回まで、行動終了ボタンで2回目をスキップ可能)
  - 通常ポーン・式神は最奥列到達で通常クイーンに成る(仮仕様)
- ターン交代、対局ログ(戦闘・召喚・破壊・変身の結果を含む)、駒図鑑パネル(基礎ステータス表示)
- キングのHPが尽きたら対局終了(簡易的な勝敗判定。本来のチェックメイト判定ではない)
- キング・クイーンは仮ステータス(要調整)で戦闘に参加

## ページ構成の現状
- トップページ：2つのモードへのリンクカードのみ。実装が進むごとにステータスバッジ(プレイ可能/準備中)を更新していく想定
- 編成モード(`formation.html`)：盤面ゲーム本体。自由に駒を編成するUIはまだ無く、初期配置固定
- ローグライクモード(`roguelike.html`)：仕様検討中のため、盤面は無く「予定している仕様」を示すだけの静的ページ
