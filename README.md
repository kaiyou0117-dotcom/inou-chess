# 異能チェス

「ここだけ異能のある世界」の設定を元にした、HP/ATK制の特殊駒チェス。GitHub Pages でそのまま公開できる構成。

## 構成
```
index.html      盤面・サイドパネルのHTML
css/style.css   デザイン(ダーク×アンティークゴールドの異能チェス風)
js/script.js    盤面ロジック・駒データ
```

## 公開方法
1. このフォルダの中身をリポジトリ直下(または `docs/` フォルダ)に配置
2. リポジトリの Settings → Pages で公開元ブランチ/フォルダを指定

## 現状の実装範囲
- 8x8盤面の表示、初期配置、駒のクリック選択、合法手ハイライト
- 標準的なチェスの動き(ポーン/ナイト/ビショップ/ルーク/クイーン/キング)による移動・捕獲
- ターン交代、簡易ログ、駒図鑑パネル
- キング捕獲で対局終了(簡易的な勝敗判定。本来のチェックメイト判定ではない)

## 未実装(次のステップ)
- **HPダメージ制の戦闘解決**：現状は着地すれば即捕獲。「ATKでHPを削り、0で捕獲」という設定を反映した戦闘ロジックに置き換える必要あり
- **各駒の特殊能力**
  - 海洋恐怖症(ビショップ)：移動時に式神(ポーン)を召喚
  - 情報の悪魔(ナイト)：移動時に縦横1マスの駒を破壊(「レンレン」で無効化)
  - 鉄拳の悪魔(ルーク)：1体限定で駒を飛び越え可能
  - 社畜魔導士(ポーン)→コードネームAMBER：成り時に動きを選択、1ターン2回移動
  - 嘘の悪魔(クイーン)：能力・ステータスともに未定
  - キング：ステータス・特殊能力ともに未定
- チェック/チェックメイト判定
- 「編成モード」「ローグライクモード」の切り替えと、勝利で駒を獲得していく周回システム
- 対戦相手(CPU / オンライン対戦 / ローカル対戦)の実装方針の確定
